# Test Routes

Use these repeatable routes when evaluating sourced candidates for promotion readiness.

## Route A - Sixth House dream pressure (both editions)

- **Primary categories:** dream-sixth-house, architecture
- **Candidate focus:** `the-dream-is-the-door`, `lucid-disturbing-dreams`, `beware-the-sixth-house`, `kogoruhn-extinct-city-of-ash-and-sulfur`
- **Path:** Balmora -> Caius Cosades progression -> Ashlands scouting -> Sixth House bases -> Kogoruhn/Cavern of the Incarnate checkpoints
- **Evidence to capture:** quest-stage stability, dream trigger reliability, dungeon pathing, encounter pacing spikes, and any hard blockers

## Route B - Blight ambience and Red Mountain atmosphere (split by engine)

- **Primary categories:** blight-ash-weather, soundscape
- **Candidate focus:** `creeping-blight` + edition-specific ambience (`it-beats-openmw` for OpenMW, `heartthrum` for MWSE)
- **Path:** Seyda Neen baseline weather -> Balmora -> Ghostfence perimeter -> Red Mountain approaches
- **Evidence to capture:** weather progression triggers, ambience trigger zones, audio layering conflicts, and performance impact in ash-heavy regions

## Route C - MWSE survival/body pressure (Sleeper Edition only)

- **Primary categories:** survival-body-horror, UI/journal
- **Candidate focus:** `ashfall`
- **Path:** New game setup -> first camp cycle -> Ashlands travel leg -> low-resource rest cycle in hostile region
- **Evidence to capture:** survival loop friction, UI readability, script reliability over long sessions, and interaction with travel/economy pacing

## Required evidence bundle per route

- Compatibility status result (`unverified`, `needs-testing`, `openmw-compatible`, `mwse-compatible`, `both-compatible`, or `conflicting-reports`)
- Conflicts found and current mitigation path
- Edition-specific behavior differences (OpenMW vs MWSE)
- Promotion recommendation (`hold`, `promote-openmw`, `promote-mwse`, `promote-both`, `reject`)
